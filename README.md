# iTycGram

当前版本：`v1.0.1`

新功能：批量屏蔽。多选消息后可一键屏蔽全部发送者与内容，过滤器页可批量添加屏蔽词（每行一条），均沿用现有过滤器逻辑。

iTycGram 是一份 Telegram Desktop 分支，界面为简体中文。

源码基于 Telegram Desktop，版权归原作者所有，授权协议是 GPL-3.0。内部目录名是 `ityc/`，翻译键前缀是 `ityc_`。

## 名称

- 程序名：`iTycGram.exe`
- 关于页标题：`iTycGram 桌面版`
