# iTycGram

当前版本：`v1.0.2`

批量屏蔽只隐藏消息内容。多选后，顶栏「转发」「消息截图」旁边有「批量屏蔽」；多选时可用 Ctrl+A 全选。过滤器页仍可批量添加屏蔽词（每行一条）。

iTycGram 是一份 Telegram Desktop 分支，界面为简体中文。

源码基于 Telegram Desktop，版权归原作者所有，授权协议是 GPL-3.0。内部目录名是 `ityc/`，翻译键前缀是 `ityc_`。

## 名称

- 程序名：`iTycGram.exe`
- 关于页标题：`iTycGram 桌面版`
